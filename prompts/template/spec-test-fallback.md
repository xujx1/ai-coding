# 测试任务清单

## Phase 1: 测试结构与依赖梳理
- [ ] 阅读开发任务清单、技术方案和现有测试目录，确认需要新增或修改的测试类。
- [ ] 检查项目现有 JUnit、Mockito、Spring Test、H2 或 MyBatis 测试依赖和基类用法。

## Phase 2: 单元测试用例生成
- [ ] 为核心 Service 成功路径生成单元测试，覆盖主要业务状态和返回结果。
- [ ] 为 Controller 或接口入口生成测试，覆盖请求字段、响应结构和 requestId 透传。

## Phase 3: Mock 与测试数据准备
- [ ] 为 Mapper、审计、幂等、外部服务等依赖准备 Mock/Stub 或测试夹具。
- [ ] 构造满足成功、失败、边界和重复提交场景的测试数据。

## Phase 4: 异常路径与回归覆盖
- [ ] 覆盖资源不存在、非法状态、幂等冲突、并发更新失败等异常路径。
- [ ] 覆盖不会影响无关关联数据或既有查询语义的回归场景。

## Phase 5: Maven 执行与报告校验
- [ ] 运行目标测试类或 Maven 单元测试命令，记录执行命令和结果。
- [ ] 修复测试编译或断言失败，确保新增测试稳定通过。
