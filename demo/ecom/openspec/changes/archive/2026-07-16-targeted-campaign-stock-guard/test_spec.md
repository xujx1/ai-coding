# 测试规格：定向营销活动库存保护

## 单元测试

| 应用 | 用例 |
|------|------|
| `ecom-product` | SKU 存在且上架时返回可售摘要 |
| `ecom-product` | SKU 未上架时返回不可售状态 |
| `ecom-product` | SKU 不存在时返回明确错误 |
| `ecom-inventory` | 可保护库存等于可用库存减活动保护库存 |
| `ecom-inventory` | 库存不足时保护失败 |
| `ecom-inventory` | 重复保护同一活动和 SKU 返回幂等成功 |
| `ecom-inventory` | 缺记录释放和重复释放返回幂等成功 |
| `ecom-marketing` | 创建阶段 SKU 未上架时失败 |
| `ecom-marketing` | 创建阶段库存不足时失败 |
| `ecom-marketing` | 创建成功后不创建库存保护 |
| `ecom-marketing` | 启用成功后创建库存保护 |
| `ecom-marketing` | 重复启用和重复删除返回成功 |

## 集成测试

1. 造数已上架 SKU 和充足库存，创建库存保护活动成功，状态为 `DRAFT`。
2. 启用该活动成功，库存保护记录为 `ACTIVE`。
3. 再次启用该活动返回幂等成功，保护数量不重复增加。
4. 删除该活动成功，库存保护记录为 `RELEASED`。
5. 再次删除该活动返回成功。
6. 使用未上架 SKU 创建活动失败。
7. 使用库存不足 SKU 创建活动失败。

## 回归测试

1. 控制台健康检查可用。
2. 商品上架演示可用。
3. 普通营销活动创建和删除可用。
4. 交易下单演示可用。
5. 交易取消演示可用。
6. 完整链路演示可用。

## 造数与清理

seed 数据：

| 数据 | 示例 |
|------|------|
| 已上架 SKU | `SKU-GUARD-1` |
| 未上架 SKU | `SKU-GUARD-OFF` |
| 充足库存 | `SKU-GUARD-1` 可用库存 100 |
| 不足库存 | `SKU-GUARD-LOW` 可用库存 1 |
| 活动 | `CAMP-GUARD-1` |

cleanup 范围：

1. 删除测试活动。
2. 删除测试库存记录。
3. 删除测试库存保护记录。
4. 删除测试 SKU。
