# 变更提案：定向营销活动库存保护

## 背景

营销活动创建和启用前缺少商品上架与库存承接能力校验，导致活动可能在商品不可售或库存不足时进入运营流程。本变更补齐创建校验、启用保护和删除释放闭环。

## 目标

1. 创建库存保护活动时校验 SKU 已上架和库存充足。
2. 创建阶段只校验库存，不保护库存。
3. 启用活动时按 `campaignId + skuId` 幂等创建活动库存保护。
4. 删除活动时幂等释放库存保护；重复删除或释放返回成功。
5. 控制台提供一键演示入口并展示跨域结果。

## 范围

| 应用 | 范围 |
|------|------|
| `ecom-console` | 新增库存保护活动操作入口 |
| `ecom-marketing` | 编排商品校验、库存校验、启用保护、删除释放 |
| `ecom-inventory` | 新增活动库存保护表和保护接口 |
| `ecom-product` | 稳定 SKU 查询和上架状态响应 |
| `ecom-trade` | 仅回归验证，不改生产代码 |

## 不做

1. 不改变交易下单扣减、支付、履约、物流链路。
2. 不引入 MQ、补偿任务或分布式事务。
3. 不支持多 SKU 活动。
4. 不把活动保护库存接入真实交易可售扣减口径。
